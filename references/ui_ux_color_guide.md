# 现代 UI/UX 东方色彩工程化落地指南

将中国传统色落地于现代移动端（App）与网页（Web）界面设计时，不能仅凭主观艺术直觉，必须将其严格纳入现代数字界面的**可用性标准（Usability）、无障碍标准（WCAG 2.1）与工程设计系统（Design Tokens）**。

---

## 一、60-30-10 黄金比例在界面中的映射规范

传统中国画讲究“惜墨如金、留白三千”。在数字 UI 界面中，60-30-10 配色模型与东方审美天然契合：

```
┌─────────────────────────────────────────────────────────────┐
│ 60% 背景与基底 (Background & Surface)                         │
│  • 避免极简刺眼的纯白 (#FFFFFF)，推荐纸本宣白、象牙白、月白      │
│  • 承担视域留白，营造温润呼吸感                                │
│                                                             │
│   ┌─────────────────────────────────────────────────────┐   │
│   │ 30% 界面结构与骨干 (Primary & Typography)            │   │
│   │  • 品牌主基调（如天青、松绿、朱红、群青）              │   │
│   │  • 导航栏、主要容器、核心卡片与大标题字重             │   │
│   │                                                     │   │
│   │   ┌─────────────────────────────────────────────┐   │   │
│   │   │ 10% 交互与高光点睛 (Accent & Feedback)       │   │   │
│   │   │  • CTA 关键动作（购买、确认、高亮徽标）       │   │   │
│   │   │  • 微交互 hover 动效、关键数据指标点缀        │   │   │
│   │   └─────────────────────────────────────────────┘   │   │
│   └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### 具体组件映射表

| 层级与比例 | 界面组件映射 | 东方色彩选型原则 | 推荐代表国色 |
| :--- | :--- | :--- | :--- |
| **60% 背景基底 (Bg/Canvas)** | 页面底衬、视口背景、大面积留白区域 | 极低饱和度、高明度，模拟古纸、绢帛或白玉质地 | **鱼肚白** `#f7f4ed`、**象牙白** `#fffef8`、**月白** `#eef7f2` |
| **表面层 (Surface/Card)** | 卡片容器、悬浮弹窗 Modal、底部导航栏 Drawer | 纯净明亮，微带有边界对比，与背景形成层次进退 | **纯素白** `#ffffff`、**粉白** `#fbf2e3` |
| **30% 结构主体 (Primary)** | Header 栏头、品牌 Tab 选中态、主要按钮、图表主轴 | 中高纯度，代表品牌精神图腾与文化身份 | **霁青** `#63bbd0`、**大红** `#f04b22`、**翠绿** `#20a162` |
| **文本排版 (Text Primary)** | 正文段落、列表标题、数据表文案 | 严禁使用硬直纯黑 `#000000`，应选用深墨或水牛灰 | **晶石紫** `#1f2040`、**钢青** `#142334`、**长石灰** `#363433` |
| **次级文本 (Text Muted)** | 副标题、时间戳、帮助提示、表单 Label | 带有微弱冷暖倾向的中灰，确保与背景对比度达标 | **田螺绿** `#5e665b`、**铅灰** `#bbb5ac` |
| **10% 交互高光 (Accent)** | 核心转化行动点（CTA）、未读红点、完成态勋章 | 采用色相环对立（150°~180°）高张力对比色 | **金叶黄** `#ffa60f`、**铁棕** `#d85916`、**晨曦红** `#ea8958` |

## 二、WCAG 2.1 无障碍对比度准则

数字界面必须确保视力障碍者与弱光环境下用户均能清晰阅读：

1. **正文与标题可读性**：
   - **AA 级要求**：普通文本（<18pt 或粗体 <14pt）与背景的对比度需 **≥ 4.5:1**。
   - **AAA 级要求**：推荐达到 **≥ 7.0:1**。
   - *东方色落地实践*：在浅宣纸白（如 `#f7f4ed`）背景上，正文不可选用中等明度的“青灰”或“竹青”，必须选用深墨色如 **钢青** (`#142334`，对比度达 14.8:1) 或 **晶石紫** (`#1f2040`，对比度达 14.3:1)。
2. **图形组件与用户界面状态**：
   - 按钮边框、输入框边框、图标对比度需 **≥ 3.0:1**。
3. **彩色按钮与文字**：
   - 当使用传统色作为实体填充主按钮时（如霁青色主按钮），内部文本需根据按钮亮度智能决定是深墨字还是白玉字。例如霁青（#63bbd0）亮度偏高，按钮内部搭配深色文字比白色文字更清晰易读。

## 三、深浅双轨自适应模式（Light / Dark Mode）

东方美学在暗黑模式下并非粗暴的反色，而是转向“夜宴墨韵、幽微观灯”的高级意境：

| 变量角色 | 浅色明朗模式 (Light Mode) | 暗夜幽玄模式 (Dark Mode) |
| :--- | :--- | :--- |
| **背景色 (`--color-bg`)** | **鱼肚白** `#f7f4ed` (微温古纸) | **燕颔蓝** `#131824` 或 **深蓝** `#101f30` (沉静夜幕) |
| **表面色 (`--color-surface`)** | **纯白** `#ffffff` | **钢青灰** `#1c2938` (青石反光) |
| **主品牌色 (`--color-primary`)** | **霁青** `#63bbd0` (通透晴岚) | **海天蓝** `#93d5dc` (微调高明度，增强深色底对比) |
| **正文文字 (`--color-text-primary`)** | **钢青** `#142334` (深邃墨字) | **象牙白** `#fffef8` 或 **羊脂白** `#f6f7f8` (温润柔光) |
| **辅助弱字 (`--color-text-muted`)** | **田螺绿** `#5e665b` | **星灰** `#b2bbbe` |
| **点睛行动 (`--color-accent`)** | **铁棕** `#d85916` | **金盏黄** `#fcc307` (暗夜火烛点睛) |

## 四、前端工程 Design Tokens 与 Tailwind 代码规范

### 1. 标准 CSS 变量模版 (`theme.css`)
```css
:root[data-theme="light"] {
  /* 背景基底 (60%) */
  --bg-canvas: #f7f4ed;      /* 鱼肚白 */
  --bg-surface: #ffffff;     /* 纯素白 */
  --border-subtle: #e4dfd7;  /* 珍珠灰 */

  /* 结构主色 (30%) */
  --primary: #63bbd0;        /* 霁青 */
  --primary-hover: #5cb3cc;  /* 碧青 */
  --secondary: #6e8b74;      /* 瓦松绿 */

  /* 文本系统 */
  --text-main: #142334;      /* 钢青 */
  --text-muted: #5e665b;     /* 田螺绿 */

  /* 交互点睛 (10%) */
  --accent: #d85916;         /* 铁棕 */
}

:root[data-theme="dark"] {
  --bg-canvas: #131824;      /* 燕颔蓝 */
  --bg-surface: #1c2938;     /* 鸽蓝 */
  --border-subtle: #2b333e;  /* 青灰 */

  --primary: #93d5dc;        /* 清水蓝 */
  --primary-hover: #51c4d3;  /* 瀑布蓝 */
  --secondary: #83a78d;      /* 松霜绿 */

  --text-main: #fffef8;      /* 象牙白 */
  --text-muted: #b2bbbe;     /* 星灰 */

  --accent: #fcc307;         /* 金盏黄 */
}
```

### 2. Tailwind CSS 配置扩展 (`tailwind.config.js`)
```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        oriental: {
          bg: 'var(--bg-canvas)',
          surface: 'var(--bg-surface)',
          primary: 'var(--primary)',
          secondary: 'var(--secondary)',
          accent: 'var(--accent)',
          text: 'var(--text-main)',
          muted: 'var(--text-muted)',
          border: 'var(--border-subtle)',
        }
      }
    }
  }
};
```
在界面中即可直接应用语义类名，如 `class="bg-oriental-bg text-oriental-text hover:bg-oriental-primary"`。

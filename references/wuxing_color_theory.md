# 东方色彩美学与五行色彩哲学体系

中国传统色彩不仅是视觉上的光谱表现，更是数千年来华夏先民对天地自然、四时流转、礼乐制度与天人合一哲学感悟的结晶。本规范整理了以“五行五色”为轴心的东方色彩宇宙观，为专业色彩搭配提供深厚的文化注脚与审美准绳。

---

《礼记·礼运》云：“播五行于四时，和四代之乐，故色有五：青、赤、黄、白、黑。”

## 二、正色与间色体系

《论语·阳货》孔子曰：“恶紫之夺朱也。” 在传统礼乐规制中，“正色”象征天地正道与君德，而两两相生杂糅派生出的为“**间色**”：

1. **绿（青 + 黄）**：木入土中，草木始萌之色，柔和生动。
2. **红（赤 + 白）**：火遇金烁，浅赤带霞，桃灼灼其华。
3. **碧（青 + 白）**：水天相映，玉质冰肌，清冽绝俗。
4. **紫（赤 + 黑）**：暗夜烈火，高贵神秘，汉唐而后渐升为至尊之服色（如紫宸殿、紫禁城）。
5. **骝黄 / 硫华（黄 + 黑）**：土水相杂，沉稳内敛，如大地黄土之润。

## 三、五行生克在配色中的和弦推导法则

东方配色讲究“气运相生、虚实相制”，可将五行生克转化为现代设计和弦准则：

### 1. 五行相生（融洽流转 · 和谐色）
- **木生火**（青绿 + 赤红）：如红梅映竹，青翠间点染朱砂，生机盎然。
- **火生土**（赤红 + 暖黄）：如故宫红墙金瓦，炽热温暖，尊崇富丽。
- **土生金**（姜黄/赭土 + 素白）：如秋收麦浪拂雪，质朴温厚，天然田园。
- **金生水**（素白 + 靛蓝/深墨）：如水墨宣纸、青花瓷器，留白幽远，空灵脱俗。
- **水生木**（深蓝/黛黑 + 翡翠/水绿）：如深潭倒影，沉静深邃，涵养生机。

### 2. 五行相克（对撞制衡 · 互补色）
- **水克火**（群青/钢青 vs 朱红/落霞）：极冷与极热对撞，极具现代视觉张力。
- **火克金**（茜红/胭脂 vs 银白/月白）：强对比中见柔情，如白里透红。
- **金克木**（霜白/铅灰 vs 翠绿/碧青）：素雅静谧中点缀青意，宋画意境。
- **木克土**（松绿 vs 栀黄）：大地逢春，层次丰富。
- **土克水**（秋葵黄 vs 鷃蓝）：黄土高原遇晴空，苍茫旷达。

## 四、传统工艺与艺术中的国色典范

1. **青铜时代（锈彩与斑驳）**：
   - 铜绿、古铜绿、水青、锈红交融，带有历史风化沉淀的肃穆与厚重感。
2. **两宋瓷器（极致的文人极简主义）**：
   - **汝窑**：天青、粉青、月白，天人合一、内敛温润、如脂如玉。
   - **定窑**：象牙白、汉白玉，单色釉的纯粹雅致。
   - **钧窑**：窑变幻化，紫红、海棠、月青于窑火中偶然天成。
3. **盛唐丝绢与壁画（绚丽热烈的万国气象）**：
   - 牡丹红、孔雀蓝、藤黄、魏紫、青莲交织，展示雍容华贵、大国包容的盛世华章。
4. **明清宫廷与文人造物**：
   - 紫禁城皇家色系（红墙、黄瓦、青绿和玺彩画、汉白玉台基）。
   - 宣德炉皮色（藏经纸色、棠梨色、栗壳色）。
   - 景德镇青花与五彩（群青蓝料沉入釉骨，与素白相映成趣）。

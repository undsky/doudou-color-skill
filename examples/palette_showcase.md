# 东方传统色彩实战案例库（Palette Showcase）

本案例库提供三个不同维度的工业级专业配色范例，包含品牌包装与四色印刷、移动端数字界面（UI/UX）以及视觉插画与海报。

---

## 案例一：新中式茶饮/文创品牌视觉体系与礼盒包装

### 1. 客户背景与需求
- **品牌名称**：“谷雨煎茶”
- **品牌调性**：高雅、沉静、文人生活美学、清甜自然
- **应用载体**：茶叶罐（马口铁哑光烤漆）、礼盒外包装（特种艺术纸）、手提纸袋（四色印刷 + 烫印工艺）

### 2. 色彩专家定制方案：“雨前春早 · 翠微煎茶”
五行属性以**木（青翠生发）**为主，配以**水（甘冽泉水）**与**金（澄明玉白）**，形成“水生木、木蕴灵”的生气流转。

| 角色/比例 | 色名 | HEX | RGB | 四色印刷 CMYK | 工艺与材质建议 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **底衬主调 (60%)** | **汉白玉** | `#f8f4ed` | `[248, 244, 237]` | `C:2 M:3 Y:6 K:0` | 选用 280g 雅致大地纸，带有微粗纤维触感，免过塑 |
| **品牌主体 (30%)** | **玉簪绿** | `#a4cab6` | `[164, 202, 182]` | `C:41 M:7 Y:34 K:0` | 茶叶罐哑光触感漆主色，柔滑如玉，散发天然茶青清气 |
| **点睛高光 (10%)** | **晨曦红** | `#ea8958` | `[234, 137, 88]` | `C:0 M:58 Y:67 K:0` | 封口贴与品牌印鉴选用，采用哑光古铜金或哑红电化铝烫金 |
| **品名排版文字** | **云杉绿** | `#15231b` | `[21, 35, 27]` | `C:85 M:68 Y:77 K:72` | 正文字体与书法 Logo，印刷深邃油墨，清晰防晕染 |
| **辅助腰封与插画** | **艾绿** | `#cad3c3` | `[202, 211, 195]` | `C:23 M:13 Y:23 K:0` | 包装内衬卡与茶品说明卡，清雅不抢视觉主体 |

### 3. 专家美学评述
> “玉簪绿若初展嫩叶，得朝露而润；汉白玉如温润古瓷，衬千般芳华。辅以晨曦红一点封缄，宛如山间云开第一道晨光破晓。清而不寡，雅而不素。”

## 案例二：国风文博移动端 App 界面（UI/UX 数字工程）

### 1. 业务场景
- **产品类型**：“华夏云博” 移动端数字藏品与文博导览 App
- **设计目标**：在智能手机 OLED/LCD 屏幕上呈现两宋文人“雨过天青”的高级灰度质感，同时确保文字可读性达 WCAG 2.1 AAA 级。

### 2. 60-30-10 配色方案与无障碍指标

```
[浅色明朗模式]
┌────────────────────────────────────────────────────────┐
│ 页面背景 (60%): 鱼肚白 (#f7f4ed) - 古纸温润留白         │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 卡片 Surface: 纯素白 (#ffffff)                    │  │
│  │ 标题排版: 钢青 (#142334) - 对比度 14.8:1 (AAA 级) │  │
│  │                                                  │  │
│  │  [ 主操作按钮 Primary (30%): 霁青 (#63bbd0) ]     │  │
│  │  [ 核心转化 CTA Accent (10%): 铁棕 (#d85916) ]   │  │
│  └──────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

### 3. 完整工程 CSS 设计令牌 (Tokens)
```css
/* 华夏云博 App - 核心设计令牌系统 */
:root {
  /* 基础画布 (60%) */
  --app-bg: #f7f4ed;            /* 鱼肚白 - 温润米白纸感 */
  --app-surface: #ffffff;       /* 素白 - 卡片底色 */
  --app-border: #e4dfd7;        /* 珍珠灰 - 极细描边 */

  /* 品牌结构 (30%) */
  --app-primary: #63bbd0;       /* 霁青 - 天青瓷釉色 */
  --app-secondary: #6e8b74;     /* 瓦松绿 - 辅助标签 */
  --app-text: #142334;          /* 钢青 - 正文深墨色 */
  --app-text-muted: #5e665b;    /* 田螺绿 - 辅助信息色 */

  /* 行动高光 (10%) */
  --app-accent: #d85916;        /* 铁棕 - 醒目转化色 */
}

/* 深色沉浸模式 (Dark Mode) */
@media (prefers-color-scheme: dark) {
  :root {
    --app-bg: #131824;          /* 燕颔蓝 - 深邃如墨夜空 */
    --app-surface: #1c2938;     /* 鸽蓝 - 青石卡片 */
    --app-border: #2b333e;      /* 青灰 - 幽微界线 */

    --app-primary: #93d5dc;     /* 清水蓝 - 提升深色底明度 */
    --app-secondary: #83a78d;   /* 松霜绿 */
    --app-text: #fffef8;        /* 象牙白 - 柔和反白字 */
    --app-text-muted: #b2bbbe;  /* 星灰 - 次级反白字 */

    --app-accent: #fcc307;      /* 金盏黄 - 灯火点睛 */
  }
}
```

## 案例三：国潮中秋文创礼盒海报（视觉传达与插画）

### 1. 创作主题
- **主题**：“月照锦瑟 · 千里婵娟”
- **视觉重心**：圆月当空、金桂飘香、玉兔捣药、层叠青绿山峦

### 2. 色彩矩阵设计

```
[远景/夜空] 鷃蓝 (#144a74) / 钢青 (#142334) -> 沉稳浩瀚之夜色
     │
     ▼
[高光/圆月] 金叶黄 (#ffa60f) / 栀子黄 (#ebb10d) -> 皎洁璀璨，明烛长空
     │
     ▼
[中景/重峦] 群青 (#1772b4) + 翠绿 (#20a162) -> 千里江山青绿重彩
     │
     ▼
[近景/点睛] 珊瑚红 (#f04a3a) / 银朱 (#f43e06) -> 印章、红灯笼、喜乐团圆
```

| 色系层级 | 色名 | HEX | 视觉动线意图 |
| :--- | :--- | :--- | :--- |
| **第一视觉焦点 (主色)** | **金叶黄** | `#ffa60f` | 明月与桂花，在深蓝夜幕中瞬间抓取受众第一目光 |
| **背景大底基调 (背景)** | **鷃蓝** | `#144a74` | 苍茫静谧的中秋长夜，衬托金月更加璀璨剔透 |
| **中景纵深层次 (辅助)** | **翠绿** | `#20a162` | 勾勒层峦叠嶂的青绿山脉，使画面具有古典空间透视感 |
| **近景暖意提振 (点睛)** | **珊瑚红** | `#f04a3a` | 窗棂红烛、落款朱印，打破冷暖失衡，增添佳节温暖人间烟火 |
| **留白光晕柔化 (过渡)** | **月白** | `#eef7f2` | 月华流泻在水面与云烟上的微光倒影，氤氲灵动 |

### 3. 专家构图提示
画面采用 50% 沉郁夜蓝沉底、30% 青绿山水穿插、15% 金黄明月提亮，最后以 5% 的朱红小品（如印章或红绳）完成色彩气韵的闭环（气贯长虹、收放自如）。

雨过天青·月白风清

汝窑的天青，是雨收云散那一刻天光落进釉里的颜色 —— 不浓不烈，却自带一层水气。 以月白铺六成底衬留出呼吸，霁青立三成骨架撑住通透，秋葵黄只点一成， 如晴日里一粒花蕊落在素纸上。全谱十二色皆出自 526 种权威国色。 「月白风清，如此良夜何」—— 苏轼《后赤壁赋》

六三一留白法则

通透感的来源不是色彩本身，而是色彩之间的留白比例。月白系占据六成以上视野， 主体色只在必要处落笔，点睛色克制到一成以内 —— 这是包装拿在手上"轻"的根本原因。

Wu Xing / 五行流转

水生木 · 木生火转土

清新感在五行上有明确路径：以水（霁青）润木（葱绿），气机自然向上升发，这是"生"而非"克"的关系， 故观感和缓、不起冲突。末端引一点土色（秋葵黄）收住，避免满盘青绿过于寒凉。

Production / 印制工艺

纸张与后道工艺建议

高明度浅色方案对纸张与工艺极其敏感 —— 同一组 CMYK 值印在铜版纸与特种纸上， 通透感差别很大。以下为落地时需要交代给印厂的要点。

纸张选型

PAPER STOCK
  • 首选特种纸：星采、丝润等微纹哑面纸，纸面本身带细腻肌理，浅色区呈现"呼吸感"。
  • 次选轻涂纸：120–157g 哑粉纸，比铜版纸少反光，避免月白区泛出塑料光泽。
  • 避开高白铜版：镜面反光会让霁青显脏、月白显灰。
  • 盒型建材：内衬可用未漂白牛皮纸，与月白形成质朴对照。

四色印刷把控

CMYK CONTROL
  • 月白 C11 M0 Y8 K0：网点极浅，务必要求印厂打样确认，防止跳网变纯白。
  • 霁青 C74 M2 Y24 K0：青版占比高，需盯紧 C 版实地密度，偏差会直接转灰或转绿。
  • 荷叶绿 K25：含黑版，深色区注意总墨量，避免背面透印。
  • 专色替代：若预算允许，霁青建议改用专色印刷，四色叠印难以稳定复现汝窑釉感。

后道工艺

FINISHING
  • 哑膜为主：切勿覆光膜，会破坏通透气质。哑膜或过油即可。
  • 烫金克制：秋葵黄区域可改烫哑光浅金，面积控制在版面一成以内。
  • 击凸留白：品牌字建议素击凸（无墨压凸），靠光影而非颜色出层次。
  • 局部 UV：仅用于圆形徽记等小面积图形，做出釉面水光感。

数字端注意

DIGITAL NOTES
  • 禁用组合已标注：霁青底白字、月白底霁青字均不可用于正文。
  • 深色模式需换轴：本方案为浅色专用，转深色应以青灰为底、艾背绿为文字。
  • 焦点态可见：输入框聚焦使用 4px 天青光圈，键盘操作可辨。
  • 动效克制：已内置 prefers-reduced-motion 降级。
Design Tokens / 工程令牌

可直接取用的 CSS 变量

复制即可用于项目，命名沿用传统色拼音，语义层另做映射，便于后期换肤。

/* 雨过天青 · 月白风清 —— 清新通透文创色谱 */
:root {
  /* 60% 底衬 */
  --yuebai:      #eef7f2;  /* 月白   CMYK 11,0,8,0 */
  --xuebai:      #fffef9;  /* 雪白   CMYK 0,1,3,0 */
  --nenjulv:     #f0f5e5;  /* 嫩菊绿 CMYK 9,1,14,0 */
  --aibeilv:     #dfecd5;  /* 艾背绿 CMYK 20,1,23,0 */

  /* 30% 主体 */
  --jiqing:      #63bbd0;  /* 霁青   CMYK 74,2,24,0 */
  --pubulan:     #51c4d3;  /* 瀑布蓝 CMYK 79,0,27,0 */

  /* 辅助 */
  --conglv:      #40a070;  /* 葱绿   CMYK 90,7,73,0 */
  --heyelv:      #1a6840;  /* 荷叶绿 CMYK 100,31,91,25 */
  --pingguolv:   #bacf65;  /* 苹果绿 CMYK 41,4,76,0 */

  /* 10% 点睛 */
  --qiukuihuang: #eed045;  /* 秋葵黄 CMYK 8,19,84,1 */

  /* 文字 */
  --qinghui:     #2b333e;  /* 青灰   CMYK 87,69,51,58 */
  --tianluolv:   #5e665b;  /* 田螺绿 CMYK 62,42,56,34 */

  /* ── 语义映射 ── */
  --bg:          var(--yuebai);
  --surface:     var(--xuebai);
  --surface-alt: var(--nenjulv);
  --border:      var(--aibeilv);
  --primary:     var(--jiqing);      /* 配字必须用 --qinghui */
  --action:      var(--heyelv);      /* 实心按钮，配 --xuebai 白字 */
  --secondary:   var(--conglv);
  --accent:      var(--qiukuihuang);
  --text:        var(--qinghui);
  --text-muted:  var(--tianluolv);
}

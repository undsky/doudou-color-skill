Production / 印制工艺

纸张与后道工艺建议

高饱和撞色对印刷的考验在于"色域" —— 青莲与孔雀蓝都处在 CMYK 色域边缘，四色胶印很难还原屏幕效果。

纸张选型

PAPER STOCK
  • 首选黑卡／深色卡纸：墨紫大面积印刷成本高且易露白，直接用深色纸打底更稳。
  • 高白铜版：若需保留孔雀蓝的通透，反而要用高白铜版纸满版印刷。
  • 金银卡纸：藤黄区域可利用金卡纸本身的金属光泽，省去烫金工序。
  • 避开牛皮纸：纸张本身的黄褐底会吃掉青莲的紫气。

四色印刷把控

CMYK CONTROL
  • 青莲 C43 M97 Y19 K8：品红版接近满版，四色印刷会偏暗偏灰，强烈建议改专色。
  • 孔雀蓝 C92 M0 Y28 K0：青版满载，属 CMYK 色域边缘色，屏幕上的鲜亮度无法完全复现。
  • 墨紫 K81：总墨量高达 281%，需与印厂确认总墨量上限，防止背印与糊版。
  • 专色优先：青莲与孔雀蓝建议各开一个专色版，这是撞色方案能否成立的关键。

后道工艺

FINISHING
  • 哑膜加局部 UV：整体哑膜压住暗场，孔雀蓝与藤黄区域局部 UV，反差即是高级感来源。
  • 烫金：藤黄改烫真金或哑金，比四色印刷的黄更有"销金"质感。
  • 击凸：主标题可素击凸，暗场中靠光影读出层次。
  • 避免过油：暗紫大面积过油易产生不均匀的光斑。

数字端注意

DIGITAL NOTES
  • 禁用组合已标注：孔雀蓝配白字、墨紫底青莲字均不可用于正文。
  • 浅色模式需换轴：本方案为暗色专用，转浅色应以雪白为底、墨紫为文字。
  • 焦点态可见：输入框聚焦使用 4px 孔雀蓝光圈，暗场中依然清晰。
  • 动效克制：已内置 prefers-reduced-motion 降级。
Design Tokens / 工程令牌

可直接取用的 CSS 变量

复制即可用于项目，命名沿用传统色拼音，语义层另做映射，便于后期换肤。

/* 青莲映日 · 孔雀销金 —— 国风撞色海报色谱 */
:root {
  /* 60% 暗场 */
  --mozi:       #310f1b;  /* 墨紫   CMYK 53,92,55,81 */
  --tanzi:      #381924;  /* 檀紫   CMYK 48,90,50,76 */

  /* 30% 主体 */
  --qinglian:   #8b2671;  /* 青莲   CMYK 43,97,19,8 */
  --weizi:      #7e1671;  /* 魏紫   CMYK 52,100,17,7 */

  /* 撞色对冲 */
  --kongque:    #0eb0c9;  /* 孔雀蓝 CMYK 92,0,28,0 */
  --tonglv:     #2bae85;  /* 铜绿   CMYK 92,0,64,0 */

  /* 10% 点睛 */
  --tenghuang:  #ffd111;  /* 藤黄   CMYK 0,21,94,0 */

  /* 文字与描边 */
  --xuebai:     #fffef9;  /* 雪白   CMYK 0,1,3,0 */
  --xinghui:    #b2bbbe;  /* 星灰   CMYK 36,20,23,2 */
  --qianniuzi:  #681752;  /* 牵牛紫 CMYK 49,100,29,32 */

  /* ── 语义映射 ── */
  --bg:         var(--mozi);
  --surface:    var(--tanzi);
  --primary:    var(--qinglian);    /* 配字用 --xuebai */
  --clash:      var(--kongque);     /* 配字必须用 --mozi */
  --clash-alt:  var(--tonglv);
  --accent:     var(--tenghuang);   /* 配字必须用 --mozi */
  --text:       var(--xuebai);
  --text-muted: var(--xinghui);
  --border:     var(--qianniuzi);
}
